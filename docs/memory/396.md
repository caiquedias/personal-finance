## Decisões técnicas
- Invocação nos use cases (opção B, decisão do Caique); sem `FluentValidation.AspNetCore` (deprecated)
- Validação roda após `dto with { UserId = id }` do controller → `UserId NotEmpty` é seguro
- Login sem MinLength: testes de lockout/throttle usam "Errada" (6 chars) e MinLength abriria vetor de enumeração; corrige 500 por NullReference com e-mail nulo
- Teto de 128 na senha mitiga DoS via Argon2; Register ganhou mínimo 8 (muda contrato)
- Guards antigos dos use cases mantidos (defesa em profundidade)
