## Decisões técnicas
- Sem `HEAD`/`OPTIONS` em `WithMethods` (preflight tratado pelo middleware) e sem `WithExposedHeaders` (frontend não lê headers de resposta)
- Asserções sobre headers `Access-Control-*`, não sobre status (middleware responde 204 mesmo ao rejeitar)
- Risco futuro: header custom novo no frontend (ex.: `X-*`) exige atualizar `WithHeaders`
