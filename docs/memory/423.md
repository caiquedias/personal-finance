- Ponto de entrada: abas dentro de `/import` (não rota nova) — decisão do Caique
- Data de início: `<input type="date">` nativo, sem lib de calendário — decisão do Caique
- Transferência interna/duplicata: só sinalizadas (badges globais `.badge-warning`/`.badge-danger`); linhas permanecem na lista — decisão do Caique
- `kind` e `sourceType` enviados como string ("Income"/"Expense", "Personal"); data `yyyy-MM-dd` em horário local, sem `toISOString()`
- Após confirmar com sucesso: `items` e `selectedFile` são limpos (impede reenvio do lote, backend sem idempotência); resumo continua visível. Erro 400 mantém os itens
