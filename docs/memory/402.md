## Decisões técnicas
- `AuditLog` insert-only como `LoginThrottle` (sem EntityBase/DeletedAt/HasQueryFilter) — exceção deliberada ao soft-delete
- Auditoria na mesma transação da ação; nada gravado em caminhos de erro
- `Details` JSON máx. 2000 (truncamento válido); só ids/`roleId`, nunca senha, hash, secret, e-mail ou nome (LGPD)
- IP gravado (≤45) via `HttpContext.Connection.RemoteIpAddress` (null se indisponível; XFF já tratado no pipeline)
- Retenção na própria issue: BackgroundService no processo da API (Render); roda no startup (compensa sleep do plano Free) e a cada intervalo; falha logada sem derrubar a app
- Enum com `EnumToNumberConverter<AuditAction,int>` explícito (`HasConversion<int>()` não registrava conversor no teste)
