## Decisões técnicas
- Data futura (UTC) rejeitada no use case (`Expense.Create` não valida; só `MarkAsPaid`)
- Expense sem categoria ou com categoria inacessível (`IsAccessibleByUserAsync`) rejeita a importação inteira; Income ignora CategoryId
- Quinzena: dia <= 15 = First, senão Second; SourceType padrão Personal (valor inválido → DomainException)
- Description > 200 rejeitada (não truncada)
- Cache de Period por (Ano, Mês) na execução; Period soft-deleted → `Reactivate()` + `UpdateAsync`
- Atomicidade: validação completa antes de gravar, um único CommitAsync

## Desvios do spec
- Nenhum. Tech debt registrado pelo Reviewer: sem FluentValidation, sem limite de tamanho da lista, data "futura" em UTC, `Enum.TryParse` sem `Enum.IsDefined` em SourceType. `ImportLegacyDataUseCase` reaproveita Period soft-deleted sem reativar (fora do escopo).
